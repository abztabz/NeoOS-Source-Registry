# Production policy

The default gateway path may select only `approved` providers. Experimental access requires an explicit consumer option and does not itself constitute production approval. Blocked and retired providers are never selected.

Credentials are injected by the consuming server environment. This repository contains environment-variable names only, never secret values.

A product may impose stricter rules than the shared registry. It may not weaken the shared registry's provider status, commercial-use boundary or privacy boundary locally.
