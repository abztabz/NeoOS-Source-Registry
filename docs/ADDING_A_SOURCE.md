# Adding a source

Do not start in a consumer product.

1. Define or reuse a capability.
2. Review the provider's official documentation and terms.
3. Record authentication, commercial/free-tier rights, source quality, quotas, freshness, coverage, privacy/data boundary and review date.
4. Set lifecycle status conservatively.
5. Add governance tests.
6. Implement a normalized adapter only when a consumer needs it.
7. Keep experimental providers fail-closed until promotion criteria are satisfied.
8. Update consumer code only after the shared registry change is valid.
