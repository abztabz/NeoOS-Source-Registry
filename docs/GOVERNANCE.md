# Governance

Provider status is a security and commercial boundary.

**Approved** means the reviewed access path is eligible for production within the recorded data boundary. **Experimental** means the provider may be evaluated but is fail-closed for ordinary production selection. **Blocked** means it must never be selected. **Retired** preserves historical governance while removing eligibility.

Approval requires review of official documentation, terms, authentication, commercial rights, free-tier restrictions, source quality, rate limits, freshness, geographic coverage, privacy implications and data reuse boundaries.

A free plan is not evidence of commercial permission. A public API directory is not an allowlist. A provider adapter is not approval. Credentials are server-side only. Safe registry views exclude secret environment names and provider execution base URLs.

Provider policy should be reviewed again when terms, pricing, licensing, API versions or material product use changes.
